# Changelog

## 1.8 — first public release

- Cheat window on **Insert** with three tabs: Cheats, Editor, Items.
- Cheats: god mode (F7), infinite mana (F8), no debuffs; view, run speed, armor and damage
  multipliers; gold and experience up to ×100; scores are not posted to Steam leaderboards by
  default; map, compass, no fog; the property of any of 39 artifacts; optional list of active
  cheats on screen.
- Editor: gold, skill points and attributes of every hero; gear of the current hero — quality,
  effect tiers, adding and removing effects, removing curses. Changes apply at once.
- Items: equip, replace and add any item of the game using the game's own functions; delete
  bag items with restore while the window is open; bag size up to 100.
- English and Russian, following the game's language or chosen by hand.
- All cheats switch off in an online game.
